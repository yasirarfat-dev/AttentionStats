# Reporting a vulnerability

There is no Google Play release or production support commitment yet. The current source and experimental Android preview are maintained on a best-effort basis; they have not received an independent security audit. Closed-testing preparation does not establish production readiness.

Use [GitHub private vulnerability reporting](https://github.com/yasirarfat-dev/AttentionStats/security/advisories/new) if available. Do not put an exploit containing personal data or secrets in a public issue. If private reporting is unavailable, open a minimal issue requesting a private reporting channel, without vulnerability details, and wait for a maintainer to supply one.

Include the affected commit, impact, and a synthetic reproduction. No response deadline or security audit is promised. The planned threat model and release gates are in [docs/SECURITY.md](docs/SECURITY.md).
