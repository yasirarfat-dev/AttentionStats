# Attention Stats support

Attention Stats is maintained by the [Attention Stats project](https://github.com/yasirarfat-dev/AttentionStats).

For non-sensitive bugs or privacy questions, [open a GitHub issue](https://github.com/yasirarfat-dev/AttentionStats/issues/new/choose). GitHub reports are public. Describe the app version, Android version, steps and expected behavior using synthetic examples. Do not include personal counts/history, target-app screenshots, account details, device identifiers or keys.

For a security vulnerability, use [private vulnerability reporting](https://github.com/yasirarfat-dev/AttentionStats/security/advisories/new), following the repository's [security policy](https://github.com/yasirarfat-dev/AttentionStats/blob/main/SECURITY.md). Do not publish exploit details or secrets in an issue.

For support or privacy questions, email **consciousbiobot@gmail.com**. Include the app version and a synthetic description of the problem. Do not attach personal history, other apps' content, device identifiers, passwords or keys. The maintainer can replace this public address in a later reviewed update.
