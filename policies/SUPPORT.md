# Attention Stats support

Attention Stats (`attention.stats`) is maintained by the [Attention Stats project](https://github.com/yasirarfat-dev/AttentionStats).

## Reporting a problem

Use **Settings → Report a problem** in the app. It drafts an email or a GitHub issue with your phone model, Android version and app versions, never your history; you can edit it before sending.

For non-sensitive bugs or privacy questions you can also [open a GitHub issue](https://github.com/yasirarfat-dev/AttentionStats/issues/new/choose). GitHub reports are public. Describe the app version, Android version, the app and screen involved, steps and expected behavior using synthetic examples. Do not include personal counts or history, screenshots of other apps, account details, device identifiers or keys.

For support or privacy questions by email, write to **consciousbiobot@gmail.com**. Include the app version and a synthetic description of the problem. Do not attach personal history, other apps' content, device identifiers, passwords or keys.

For a security vulnerability, use [private vulnerability reporting](https://github.com/yasirarfat-dev/AttentionStats/security/advisories/new), following the repository's [security policy](https://github.com/yasirarfat-dev/AttentionStats/blob/main/SECURITY.md). Do not publish exploit details or secrets in an issue.

## What to check after an update

1. Your history from the earlier version is still there.
2. Counting still works on the supported screens you use. Support varies by app version and language; missed or misclassified items are possible, and returning to an item in the same unlock session is a revisit.
3. Breaks, limits, schedules, focus sessions and covers still behave as you set them, and Android Settings, Home and emergency calls stay reachable.
4. Optional auto-scroll, if you use it, stops when you press Stop and may be unavailable for some apps.

If something is wrong, report it as described above. There is no automatic feedback upload.
