## HUD and encounter clarification — ADR-052 / 2026-10-29

User explicitly distinguishes temporary HUD hiding, persistent display settings and pausing collection. HUD Hide lasts until departure from the current app while observations continue; only app display settings persistently turn the counter off. Pause counting remains a separate action until resumed. The user also requests compact HUD access to auto-scroll, with no first-use explanations in the HUD. If consent is needed, open the app's Convenience screen; accepted session toggles then work directly. No change grants observation, starts automation or treats hidden UI as disabled collection.
