# Contributing

Start with [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) and the shared [development rules](docs/AGENT-RULES.md). Check the [tracker](docs/FEATURE-TRACKER.md) before proposing work. This is a documentation foundation, not a working application.

Use public issues for synthetic bug reports and feature proposals. Keep real usage history, screenshots of personal devices, account details, credentials, and private reference material out of issues and pull requests. Report vulnerabilities through [SECURITY.md](SECURITY.md).
